# Experiment-Sandbox

# What is this project?
This is a personal project taking simple school/college science experiments and recreating them in simulation.

Aim: The aim is to take school experiments like titrations or circuit breaking and recreate them in a simulated environment. The simulated experiment models how experiments go and uses synthetic data to create an experimentation workflow.

# How are the experiments structured?

1. You get your experiment and turn it into a methodology and series of tasks.
2. The tasks get placed in a job queue as if it was an IRL to-do-list.
3. Each task is executable/runnable in simulation by the user. With each run, the program will record a detailed log to an external document. This is to maintain good scientific documentation practices like in real life.
4. Results of the simulated experiment are stored in a database and visualised -> options are integration with: Power BI, Streamlit or Self-Designed.
5. Insights can be made from the visualised database.
6. The experiment can be altered and different hypotheses can be tested to compare results with.
